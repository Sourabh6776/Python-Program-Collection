## About the Project

The Python Programs Collection is a beginner-friendly project that demonstrates fundamental Python programming concepts, including loops, functions, exception handling, lists, tuples, and dictionaries.

## Features

### 1. Factorial Calculator
Calculates the factorial of a non-negative integer using a loop.

Example:
- Input: `5`
- Output: `120`

### 2. Fibonacci Series Generator
Generates the requested number of Fibonacci sequence values.

Example:
- Input: `7`
- Output: `[0, 1, 1, 2, 3, 5, 8]`

### 3. Structure-to-Dictionary Conversion
Converts a sequence of key-value pairs into a Python dictionary.

The demonstration includes:
- Name
- College
- Course
- Semester

## How to Run

1. Install Python 3 on your computer.
2. Open the project folder in Cursor.
3. Open the integrated terminal.
4. Run the following command:

```bash
python python-programs/main.py
```

5. Select an option from the menu.
6. Follow the on-screen instructions.
